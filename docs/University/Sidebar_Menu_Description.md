Guest sidebar menu:
- Sign in
- General schedule
- Main page


User sidebar menu:
- Sign out
- Profile
- My Schedule
- General Schedule
- Main page


Admin sidebar menu:
- Sign out
- Profile
- My Schedule
- General Schedule
- Main page
- Deactivate user
- Create user account


Sidebar Menu Description:


The guest sidebar menu fuctionality:
- The guest can click on sign in button via sidebar menu.
- The guest is able to navigate to General Schedule page via sidebar menu.
- The guest is able to navigate to Main page via sidebar menu.


The user sidebar(extended from guest sidebar menu) menu functionality:
- The user can navigate to "My Schedule" page via sidebar menu.
- The user can navigate to "Profile" page via sidebar menu.


The admin (extended from user sidebar menu) sidibar menu functionality:
- This menu has button for removing user accounts.(This button will be called: deactivate user)
- This menu has button for creating student, teacher or admin accounts.(This button will be called: create user account)
